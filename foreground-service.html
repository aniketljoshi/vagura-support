Vagura: local game hosting

This recording shows the signed version 92 release on an Android 16 emulator. Five simulated player sessions connect to the host's non-loopback network address. The video is review evidence, not a record of Google Play beta participation.

Open the demonstration video directly

The host opens the game room, shows the town and card preview, then moves into the background. Its persistent notification shows five players, the local join address and a Close the room action. The automated test verifies that a player can still fetch its card while the host is backgrounded, then exercises the same service stop action. All player names are fictional test fixtures.

The foreground service keeps the HTTP room reachable throughout a user-started game; deferred work cannot keep remote players connected. It does not send data to a developer backend. The narrator can stop hosting at any time.
